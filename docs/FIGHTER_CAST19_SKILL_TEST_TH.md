## สินทรัพย์ภาพที่ยังต้องนำเข้าก่อนรับรอง

`game/sprites/fighter_cast19_user.webp`

ขนาด 1752×1280, WebP โปร่งใส, 6 คอลัมน์ × 4 แถว ใช้งาน 19 ช่อง ความยาวเฟรมไม่เท่ากัน

SHA-256 ที่ตรวจจากไฟล์ภาพต้นฉบับในแพ็กเจ้าของ:
`414161a85092355712e6ad1b3522c0497bbce950bfa16431055c92bfde3bff1e`

**ไฟล์ไบนารีตัวจริงยังไม่ได้เพิ่มลง GitHub PR**; ตัวเชื่อมจะใช้ fallback หากไม่มีไฟล์นี้

## หลักฐานและข้อจำกัดการทดสอบ

- Playwright Chromium รันกับ **WebP จริงที่เจ้าของอนุมัติ** ใน mini harness ของท่าและตำแหน่งภาพ: 9 สกิล × 4 ทิศ = 36/36 ผ่าน แต่ *ไม่ใช่การล็อกอินเกม*
- GitHub Actions มี Node test เช็กเลขเฟรมที่ยืนยันและ fallback.
- GitHub Actions ทดสอบ `useSkill()` ของเกมจริงผ่าน local HTTP, login, WebSocket และ Chromium/WebKit จำลอง โดยใช้ **ภาพ fixture ที่สร้างชั่วคราว** เพื่อทดสอบทางเดินโค้ด ไม่ใช่ภาพที่เจ้าของอนุมัติ. อย่าแปลว่าภาพจริงได้รับรองผ่านจากชุดนี้
- ต้องรันทดสอบใหม่ใน repo ด้วยไบนารีภาพต้นฉบับ SHA เดิมก่อน Merge; ต้องตรวจ Android/iPhone เครื่องจริงอีกครั้ง
- ห้ามแตะฐานข้อมูล Render production หรือ Deploy ทับเกมหลัก
