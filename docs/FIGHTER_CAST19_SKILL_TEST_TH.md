- `game/sprites/skfx_fighter.webp`: เอฟเฟกต์ด้านข้าง 9 สกิล × 5 จังหวะเดิมของเกม.

- `game/sprites/tiger_walk.webp`: สไปรต์เสือเกมเดิมสำหรับเอฟเฟกต์สายสัตว์ร้าย.

## วิธีเปิดทดสอบในสาขานี้

รันเซิร์ฟเวอร์ local พร้อมฐานข้อมูลแยกตาม README ของ repo แล้วเปิด:

`http://127.0.0.1:<port>/?splash=0&fightercast19=1`

พารามิเตอร์ `fightercast19=1` เปิดทั้ง Cast19 และ Fighter VFX ร่วมกันโดยอัตโนมัติ (ตั้งใจให้ใช้สวิตช์เดียว). ไม่ใช้พารามิเตอร์นี้ หน้าเกมจะเหมือนเดิม.

ล็อกอินด้วยบัญชีทดสอบอาชีพนักสู้ที่ปลดล็อกสกิลจริง และกดสกิลช่อง 3–11 ตามเงื่อนไขเกม ไม่สร้างท่าโจมตีปลอมหรือเปลี่ยนคูลดาวน์.

## ตรวจสอบอัตโนมัติ

- `tools/fighter-cast19-hook-test.js`: ตรวจเลข 19 เฟรมตรงต้นฉบับและคุ้มครองการโจมตีปกติ ตัวละครหญิง อาชีพอื่น และภาพผู้เล่นอื่น.
- `tools/fighter-cast19-real-skill-test.js`: ตรวจ HTTP login, WebSocket, `useSkill(3–11)` จริงกับฐานข้อมูล SQLite แยกและสกิลที่ปลดล็อก; ตรวจ Cast19 ดึงเฟรมถูกต้อง **พร้อมกับ** VFX ของสกิลนั้นและทิศนั้น.
- CI `.github/workflows/fighter-cast19-skill-integration.yml`: Chromium Android จำลอง และ WebKit iPhone จำลอง; ตรวจ SHA-256 ของไฟล์จริงใน repo ก่อนรัน **ไม่สร้างภาพจำลองอีกแล้ว**.

ผลทดสอบต้องดูจาก GitHub Actions ล่าสุด; ห้ามรายงาน PASS ถ้า CI ยังไม่เสร็จหรือทดสอบกับไฟล์ที่ไม่ตรง SHA.

## ข้อจำกัด / ก่อน Merge

- เป็น visual integration; ยังไม่ใช่การยืนยันรูปแบบดาเมจ hitbox การล็อกเป้าหมาย หรือประสิทธิภาพ FPS บนอุปกรณ์จริง.
- ต้องตรวจภาพจริงทุกสกิลเพื่ออนุมัติความสวยงาม ตำแหน่งแสง ระยะเอฟเฟกต์และ timing.
- ต้องทดสอบ Android/iPhone เครื่องจริง และสำรองข้อมูล production ก่อน deploy.
- ยังไม่ Merge เข้าเกมหลักบน Render; เกมออนไลน์ production และข้อมูลผู้เล่นจริงไม่ได้เปลี่ยน.
