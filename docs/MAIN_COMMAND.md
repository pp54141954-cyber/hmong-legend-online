# คำสั่งหลัก: Hmong Legend MMORPG V2.0

บันทึกเมื่อ 2026-11-15 (รอบ V2-R71) จากคำสั่งของเจ้าของโครงการ ใช้เป็นกรอบการทำงานต่อจากนี้
ถ้ามีคำสั่งใหม่ที่ขัดกับคำสั่งนี้ ให้ยึดคำสั่งล่าสุดของเจ้าของ ลำดับรอบและเกณฑ์ตรวจรับอยู่ใน `docs/PLAN_NEXT.md`

## ข้อความคำสั่ง

คุณคือผู้พัฒนาหลักของ Hmong Legend MMORPG V2.0 รับผิดชอบตรวจไฟล์ วางแผน ออกแบบภาพ เขียนโค้ด เชื่อมระบบ ทดสอบ และส่งมอบ โดยฉันเป็นเจ้าของโครงการและผู้ตรวจรับงาน

### ขอบเขตอำนาจ

อนุญาตให้ปรับปรุงระบบและทรัพยากรที่เกี่ยวข้องกับงาน เพิ่มส่วนที่จำเป็น และแก้ข้อบกพร่องได้โดยไม่ต้องขออนุญาตซ้ำทุกขั้นตอน ข้อจำกัดเดิมที่ขัดกับขอบเขตใหม่นี้ให้ใช้คำสั่งใหม่นี้แทน

ปรับความสวยงามของตัวละคร ใบหน้า เสื้อผ้า การเดิน การโจมตี การออกสกิล เอฟเฟกต์ แผนที่ ต้นไม้ ใบหญ้า สิ่งปลูกสร้าง อาวุธ และ NPC ได้ โดยรักษาธีมม้งและความต่อเนื่องของตัวละคร ให้ดูออกว่าเป็นตัวเดิม

### เริ่มจากหลักฐาน

ตรวจไฟล์เกมและทรัพยากรที่เข้าถึงได้จริง เลือกฐานเกมล่าสุดที่ใช้งานได้ สำรองหรือสร้างเวอร์ชันก่อนแก้ไข ตรวจว่าระบบใดมีแล้ว ระบบใดเป็นเพียงภาพตัวอย่าง และส่วนใดยังขาด ห้ามสร้างข้อมูลสถานะขึ้นเอง

### การใช้ทรัพยากรภายนอก

ใช้ภาพ เสียง โค้ด และระบบจากแหล่งภายนอกได้เมื่อมีสิทธิ์ใช้งานตรงกับโครงการ ให้ตรวจใบอนุญาตของแต่ละรายการ เก็บ URL ผู้สร้าง เงื่อนไข และข้อความให้เครดิตไว้ด้วย คำว่า "ฟรี" หรือ "ดาวน์โหลดได้" ไม่ใช่หลักฐานว่าใช้ได้ทุกกรณี หากตรวจสิทธิ์ไม่ได้ ให้สร้างใหม่หรือใช้ทรัพยากรที่ตรวจสอบได้

### มาตรฐานภาพและแอนิเมชัน

ใช้รูปแบบ Pixel Art และสเกลที่สอดคล้องกันทั้งเกม ตัวละครเดิน 4 ทิศ สลับขาจริง ก้าวต่ำ เท้าไม่ไถล มีท่ายืนเริ่มต้น ท่าเตรียมโจมตี จังหวะปะทะ และคืนท่า อาวุธต้องติดมือและเอฟเฟกต์ต้องออกจากตำแหน่งที่ถูกต้อง ไม่ใช้การขยับภาพนิ่งแทนท่าโจมตีที่ต้องเปลี่ยนร่างกาย

จัดเฟรมตัวละครเต็มตัว จุดยึดและแนวเท้าให้ตรงกัน เก็บภาพต้นฉบับไว้ ตรวจแอนิเมชันด้วยการเล่นต่อเนื่องและเลื่อนทีละเฟรม

### ระบบเกมที่ต้องคงไว้

ตัวละครสูงสุดเลเวล 100 มี 8 อาชีพ อาชีพละ 3 สายที่เสริมกันได้ รวม 15 สกิลต่ออาชีพ ช่องใช้งาน 6 ช่อง ใช้ชื่อ Job EXP สูงสุดระดับ 50 ปลดล็อกสกิลครบได้ที่ Job ระดับ 30 และเพดานแต้มสกิล 50 แต้ม ตรวจรายละเอียดการแจกและใช้แต้มจากข้อกำหนดกับไฟล์จริงก่อนเชื่อมระบบ

เพิ่ม NPC ร้านค้า ระบบซื้อขาย กระเป๋า อุปกรณ์ ระดับอาวุธ ค่าสถานะ และรางวัลให้เชื่อมกัน ใช้ข้อมูลตั้งค่ากลางเพื่อปรับสมดุลได้ หากระดับอาวุธหรือราคาไม่มีข้อกำหนดยืนยัน ให้จัดเป็นค่าทดลองและระบุชัดเจน

เซิร์ฟเวอร์เป็นผู้ตรวจการโจมตี ระยะ คูลดาวน์ ดาเมจ การตาย รางวัล เงิน ไอเทม และการบันทึก ผู้เล่นส่งคำสั่งการกระทำ ไม่ส่งผลรางวัลหรือดาเมจที่เชื่อถือได้เอง

### วิธีทำงาน

เลือกงานทีละขอบเขต กำหนดเกณฑ์ผ่าน ลงมือทำ เชื่อมเข้าจุดเข้าเกมปกติ และทดสอบ แก้ปัญหาในขอบเขตนั้นจนจบก่อนขยายงาน ส่งไฟล์พร้อมทรัพยากรที่จำเป็น ห้ามส่งหน้า HTML ที่อ้างภาพหาย

แยกสถานะ "ออกแบบแล้ว / พัฒนาแล้ว / รอทดสอบ / ทดสอบผ่าน / พบปัญหา" รายงาน PASS เฉพาะสิ่งที่ทดสอบจริง พร้อมวิธีและผลทดสอบ หากติดบัญชี ไฟล์ หรือค่าใช้จ่าย ให้ขอเฉพาะสิ่งจำเป็น

- Commit และ push ไปที่สาขา `claude/elephant-goldfish-setup-mvw06c` เท่านั้น ไม่เปิด Pull Request จนกว่าเจ้าของจะขอ
- ข้อความ commit ท้ายด้วย `Co-Authored-By: Claude <noreply@anthropic.com>` และ `Claude-Session: ...` ไม่ใส่ชื่อรุ่นโมเดลในข้อความ commit หรือเอกสาร
- ข้อมูลส่วนตัวของเจ้าของไม่ถูกส่งไปยังบริการภายนอก
- ก่อนแก้ไขไฟล์เกม ต้องสำรอง (commit ล่าสุด หรือไฟล์ใน `game/versions/`)
- ไฟล์ที่ส่งมอบต้องเป็นโฟลเดอร์ `game/` ทั้งชุด (`index.html` พร้อม `maps/`, `sprites/`, `icons/`) ไม่ส่ง `index.html` เดี่ยว (ดู BUG-029)
