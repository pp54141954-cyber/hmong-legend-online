# ข้อความแจ้งผลกระเป๋าและร้านค้า (R83)

ฐาน: สาขา `feature/bag-hud-r82-20261115` ที่ commit `88c209b` (R82 ของเจ้าของ) ทำงานในสาขา `feature/bag-feedback-r83` ไม่แก้เกมหลักและไม่เปลี่ยนสมดุลหรือ `shared/world.js`

## สิ่งที่เปลี่ยน

- เซิร์ฟเวอร์: ไม่เปลี่ยนเหตุผลที่ส่งกลับ ตรวจแล้วว่าทุกเหตุผลถึงหน้าจอผ่าน WebSocket จริง (`tools/feedback-ws-test.js`) เปลี่ยนเฉพาะค่า `ver` ของ `/healthz` เป็น `V2-R83`
- เกม: ตารางข้อความ `FB` แทน `SHOP_MSG` และ `DENY` เดิม ข้อความบอกสิ่งที่ผู้เล่นทำต่อได้ เช่น จัดกระเป๋าก่อน หรือยังไม่ต้องใช้ยา
- `save-error`: ข้อความบอกว่ายังไม่ได้ซื้อ ใช้ หรือสวม และไม่มีคำว่าสำเร็จ เซิร์ฟเวอร์คืนเงิน กระเป๋า และอุปกรณ์เดิมก่อนส่งผลนี้
- การเชื่อมต่อขาด: คำสั่งกระเป๋าและร้านค้าที่กดตอนขาดการเชื่อมต่อจะไม่ถูกส่งแบบเงียบ ๆ แต่แจ้งว่ายังไม่ได้ทำรายการ ป้ายสถานะยังบอกว่าหลุดหรือกำลังเชื่อมต่อใหม่
- `say()` รับระยะเวลาแสดงข้อความ ข้อความผลปฏิเสธแสดง 4 วินาที (เดิม 2.4 วินาที)

## ขอบเขตและข้อจำกัด

- ยังไม่ได้ทดสอบบนโทรศัพท์จริงหรือบนเซิร์ฟเวอร์ Production ผลทั้งหมดเป็นการจำลองอุปกรณ์
- คูลดาวน์ยาแสดงข้อความทั่วไป ไม่บอกวินาทีที่เหลือ เพราะเซิร์ฟเวอร์ไม่ได้ส่งค่านี้
- เมื่อคำสั่งถูกส่งไปแล้วแต่การเชื่อมต่อหลุดก่อนได้รับคำตอบ ผลของคำสั่งนั้นยังไม่ยืนยัน ข้อความ "ยังไม่ได้ทำรายการ" ใช้เฉพาะกรณีที่คำสั่งไม่ได้ถูกส่ง หลังเชื่อมต่อใหม่เซิร์ฟเวอร์ส่งกระเป๋าและเงินปัจจุบันให้ใหม่
- ไม่มีการเปลี่ยนค่า `CFG`, เศรษฐกิจ, ราคา หรือ `shared/world.js`
- ยังไม่ได้ deploy ขึ้น Render และยังไม่ได้เปิด Pull Request จนกว่าเจ้าของจะตรวจผล
