# เช็กลิสต์ทดสอบข้อความกระเป๋าและร้านค้าบนโทรศัพท์จริง (R83)

สถานะ: **ยังไม่ได้ทดสอบบนโทรศัพท์จริง** ผลทั้งหมดที่มีตอนนี้เป็นการจำลองอุปกรณ์ (ดู `docs/BAG_R83.md`) ผู้ทดสอบต้องกรอกตารางด้านล่างหลังทดสอบจริงเท่านั้น

## เตรียมก่อนทดสอบ
- ใช้เซิร์ฟเวอร์ทดสอบ ไม่ใช่บัญชีผู้เล่นจริง และไม่เก็บข้อมูลส่วนตัวของผู้ทดสอบไว้ในไฟล์นี้
- บัญชีทดสอบต้องมีเงิน 0 และยาสมุนไพรเล็กอย่างน้อย 2 ชิ้นในกระเป๋า
- ใช้โทรศัพท์ 2 เครื่อง: Android ผ่าน Chrome และ iPhone ผ่าน Safari
- บันทึกรุ่นเครื่องและเวอร์ชันระบบปฏิบัติการทุกครั้งที่กรอกผล

## ขั้นตอน (ทำทั้งสองเครื่อง)
1. **เงินไม่พอ**: เปิดร้านค้า แตะ "ซื้อ ยาสมุนไพรเล็ก" → ต้องเห็น `เงินไม่พอ · ซื้อสินค้านี้ไม่ได้` ประมาณ 4 วินาที และเงินกับจำนวนยาไม่เปลี่ยน
2. **HP เต็ม**: เปิดกระเป๋า แตะ "ใช้ ยาสมุนไพรเล็ก" ตอน HP เต็ม → ต้องเห็น `HP เต็มแล้ว · ยังไม่ต้องใช้ยา (ยาไม่ถูกใช้)` และจำนวนยาไม่ลด
3. **คูลดาวน์ยา**: ให้ HP ต่ำ (เช่น ถูกมอนสเตอร์โจมตี) แล้วแตะใช้ยาติดกันสองครั้ง → ครั้งที่สองต้องเห็น `ยานี้ยังอยู่ในช่วงรอ · ใช้ได้อีกใน N วินาที` และจำนวนยาลดเพียงครั้งเดียว
4. **กระเป๋าเต็ม**: ใช้บัญชีที่มีของครบ 30 ช่อง แล้วซื้อของจากร้าน → ต้องเห็น `กระเป๋าไม่มีช่องว่าง · จัดกระเป๋าก่อนซื้อ` และเงินไม่ลด
5. **สวมอุปกรณ์ของอาชีพอื่น** (ถ้ามีในกระเป๋า): แตะสวม → ต้องเห็น `อาชีพนี้สวมชิ้นนี้ไม่ได้`
6. **ถอดตอนกระเป๋าเต็ม**: แตะช่องอุปกรณ์ที่สวมอยู่ตอนกระเป๋าเต็ม → ต้องเห็น `ถอดไม่ได้ · กระเป๋าไม่มีช่องว่าง จัดกระเป๋าก่อน` และอุปกรณ์ยังสวมอยู่
7. **การเชื่อมต่อขาด**: เปิดกระเป๋าแล้วปิดสัญญาณ (Wi-Fi และข้อมูลมือถือ) → ป้ายสถานะต้องขึ้นว่า `หลุดการเชื่อมต่อ` หรือ `กำลังเชื่อมต่อใหม่` จากนั้นแตะใช้ยาหรือซื้อของ → ต้องเห็น `ยังไม่ได้ทำรายการ · ขาดการเชื่อมต่อ กำลังเชื่อมต่อใหม่` และไม่มีการเปลี่ยนแปลงในเกม
8. **เชื่อมต่อกลับ**: เปิดสัญญาณใหม่ → ป้ายต้องกลับเป็น `ออนไลน์` และกระเป๋ากับเงินต้องตรงกับเซิร์ฟเวอร์ (ตรวจจำนวนยาและเงิน)
9. **ความอ่านง่ายและการแตะ**: ข้อความอ่านได้โดยไม่ต้องขยาย ปุ่มทั้งหมดยังแตะได้ และไม่มีอะไรบังปุ่มร้านค้าหรือปุ่มกระเป๋า
10. **บันทึกไม่สำเร็จ (ข้ามได้บนมือถือ)**: ข้อความ `บันทึกไม่สำเร็จ · ยังไม่ได้ซื้อ/ใช้/สวม ของและเงินยังเหมือนเดิม ลองอีกครั้ง` ต้องให้ทีมจำลองความล้มเหลวของฐานข้อมูลบนเซิร์ฟเวอร์ ทดสอบจากมือถือโดยตรงไม่ได้
