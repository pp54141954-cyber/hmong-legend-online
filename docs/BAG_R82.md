# Hmong Legend MMORPG V2.0 — กระเป๋า R82 (15 พฤศจิกายน 2026)

## เป้าหมาย
แก้ปัญหา BUG-011: หน้ากระเป๋าทับป้ายสถานะออนไลน์ที่อยู่ใต้ HUD และปรับข้อความตอบกลับเมื่อผู้เล่นทำรายการไอเทมไม่สำเร็จ โดยไม่ออกแบบตัวละครใหม่ ไม่เปลี่ยนแผนที่และไม่แก้สมดุลเกม

## ฐานและไฟล์ที่เปลี่ยน
- แตกสาขา `feature/bag-ux-r82-20261115` จาก `feature/bag-integrity-r81-20261115` ที่ผ่าน CI รอบ R81
- `game/index.html`: เพิ่มบรรทัด `#bag-online-status` ซึ่งแสดงค่าปัจจุบันจาก `#netst`, และอัปเดตได้ขณะเปิดกระเป๋า การเชื่อมต่อหลุด/กลับมาออนไลน์จะเปลี่ยนข้อความเดียวกัน
- `game/index.html`: เพิ่ม `#bag-feedback` (role=alert) สำหรับรหัสปฏิเสธจากเซิร์ฟเวอร์ เช่น `hp-full`, `bag-full`, `wrong-class`, `save-error`, ล้างข้อความเตือนเดิมก่อนคำสั่งถัดไป
- `game/index.html`: เมื่อขาดการเชื่อมต่อ การแตะใช้/สวม/ถอดไอเทมจะแสดงเหตุผลแทนการไม่ตอบสนอง
- `tools/bag-ux-r82-test.js`: ทดสอบเปิดหน้ากระเป๋าหลังล็อกอิน ตรวจสถานะออนไลน์ในแผง กดใช้ยาเมื่อ HP เต็มให้เซิร์ฟเวอร์ปฏิเสธ ตรวจว่าไอเทมไม่ลด กดถอดและสวมโล่กลับ ข้อความเตือนล้าง และไม่มี JS error / requestfailed
- `.github/workflows/bag-ux-r82.yml`: ตรวจ Chromium Pixel 7 และ WebKit iPhone 13 ใน environment แยก, regression กระเป๋า R81 และ R78; ถ่ายภาพก่อนตรวจรับ

## ข้อจำกัด
- การเห็นสถานะในแผงกระเป๋าไม่ได้เปลี่ยนตำแหน่งป้าย #netst ในหน้าเกม ส่วนเดิมยังใช้ตำแหน่งเดิมเมื่อปิดกระเป๋า
- การส่งรายการและการคำนวณเงิน/ไอเทมอยู่บนเซิร์ฟเวอร์ตาม R81; ฝั่ง UI เพียงส่งคำสั่งและแสดงผล
- ยังไม่ได้ Deploy ทับ Render และยังไม่ได้ทดลองบนโทรศัพท์ Android/iPhone จริง
- หาก CI ล่าสุดยังไม่เสร็จ ให้ถือเป็น **รอทดสอบ** จนกว่าจะดูผลของ commit ปัจจุบันจาก Actions
- ไม่รวมโค้ดเข้าฐาน VFX หรือ main โดยอัตโนมัติ

## เกณฑ์ตรวจรับ
1. เปิดกระเป๋าบน Android Chromium/iPhone WebKit แล้วเห็น `#bag-online-status` อยู่ภายในแผงและแสดงชื่อผู้เล่น
2. ใช้ยาเมื่อ HP เต็มแล้ว `#bag-feedback` ขึ้นข้อความ พร้อมตรวจว่าจำนวนไอเทมใน SQLite ไม่ลด
3. กดถอด–ใส่โล่ได้และสถานะยังอยู่เมื่อหน้ากระเป๋าวาดใหม่
4. ไม่มี pageerror, requestfailed หรือ scroll แนวนอน
5. ผลทดสอบทั้งหมดต้องผ่านบน GitHub Actions ของสาขา R82 และมีภาพประกอบ
