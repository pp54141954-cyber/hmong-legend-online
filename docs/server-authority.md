# หน้าที่ของเซิร์ฟเวอร์ในการต่อสู้ (ทดสอบผ่าน V2-R3)

หลักการ: เครื่องผู้เล่นส่งแค่ "ขอทำอะไร" เซิร์ฟเวอร์เป็นผู้ตัดสินผลทุกอย่าง แล้วส่งผลกลับ

## เครื่องผู้เล่นส่ง

| ข้อความ | ข้อมูล |
| --- | --- |
| `mv` | ตำแหน่งที่เครื่องเดินไป, ทิศ, โซน (เซิร์ฟเวอร์ตรวจความเร็ว เส้นทางชน ขอบแมพ จุดย้ายโซน — ไม่ผ่านส่ง `fix` ดึงกลับ) |
| `act` | `k='b'` ท่าพื้นฐาน หรือ `k=1..11` สกิล, ทิศที่หัน |
| `inv` | `op=use/equip` + ช่องในกระเป๋า หรือ `op=unequip` + ชื่อช่องอุปกรณ์ |

## เซิร์ฟเวอร์ตรวจและตัดสิน

| เรื่อง | ตรวจอะไร |
| --- | --- |
| ตำแหน่ง | ความเร็วไม่เกิน `CFG.player.speed`, ไม่ทะลุช่องชน, อยู่ในแมพ |
| การโจมตี | ไม่อยู่ในคูลดาวน์, ไม่ตาย, ไม่กำลังร่ายท่าอื่น, Job ถึงเลเวลปลดล็อก (ยังไม่มีระบบช่องใช้งาน 6 ช่อง — รอข้อกำหนด) |
| เป้าที่โดน | คำนวณรูปทรงท่า (`Combat.inShape`) จากตำแหน่งบนเซิร์ฟเวอร์ ไม่รับรายชื่อเป้าจากเครื่องผู้เล่น |
| ดาเมจ | สุ่มและคิดคริติคอลบนเซิร์ฟเวอร์ (`Combat.damage`) |
| มอนสเตอร์ | AI ไล่ กลับจุด ตาย เกิดใหม่ ทำงานบน tick ของเซิร์ฟเวอร์ |
| รางวัล | EXP, Job EXP เพิ่มเฉพาะบนเซิร์ฟเวอร์ และบันทึกลงฐานข้อมูล และของดรอปตามตาราง `CFG.drops` |
| ข้อมูลผู้เล่น | Lv, EXP, Job, Job EXP, HP, กระเป๋า, อุปกรณ์ เขียนเฉพาะเซิร์ฟเวอร์ (แต้มสกิล: รอข้อกำหนด) |

## โค้ด

- กติกาและข้อมูล: `shared/world.js` (สร้างจาก `game/index.html` ด้วย `node tools/extract-shared.js` — แก้เกมแล้วต้องรันใหม่; `tools/online-test.js` ตรวจว่าตรงกัน)
- การจำลอง: `server/sim.js`
- ท่าที่ขยับตัว คิดจากตำแหน่งตอนกดและวางปลายทางเป็นค่าคงที่ (กันขยับซ้ำ)
- เครื่องผู้เล่นยังเล่นภาพท่าเองทันที (ไม่รอเซิร์ฟเวอร์) แต่ตัวเลขดาเมจ รางวัล HP มาจากเซิร์ฟเวอร์เท่านั้น
- รางวัลตอนนี้ให้ผู้ที่ตีตัวสุดท้าย (ระบบปาร์ตี้จะมาแบ่งทีหลัง)
