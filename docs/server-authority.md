# หน้าที่ของเซิร์ฟเวอร์ในการต่อสู้ (ออกแบบแล้ว — ยังไม่มีโค้ด)

หลักการ: เครื่องผู้เล่นส่งแค่ "ขอทำอะไร" เซิร์ฟเวอร์เป็นผู้ตัดสินผลทุกอย่าง แล้วส่งผลกลับ

## เครื่องผู้เล่นส่ง

| ข้อความ | ข้อมูล |
| --- | --- |
| `move` | ทิศที่กด (dx, dy) และเลขลำดับ input |
| `attack` | ทิศที่หัน |
| `skill` | เลขสกิล, ทิศที่หัน |

## เซิร์ฟเวอร์ตรวจและตัดสิน

| เรื่อง | ตรวจอะไร |
| --- | --- |
| ตำแหน่ง | ความเร็วไม่เกิน `CFG.player.speed`, ไม่ทะลุช่องชน, อยู่ในแมพ |
| การโจมตี | ไม่อยู่ในคูลดาวน์, ไม่ตาย, ไม่กำลังร่ายท่าอื่น, Job ถึงเลเวลปลดล็อก, มีสกิลในช่องใช้งาน |
| เป้าที่โดน | คำนวณรูปทรงท่า (`Combat.inShape`) จากตำแหน่งบนเซิร์ฟเวอร์ ไม่รับรายชื่อเป้าจากเครื่องผู้เล่น |
| ดาเมจ | สุ่มและคิดคริติคอลบนเซิร์ฟเวอร์ (`Combat.damage`) |
| มอนสเตอร์ | AI ไล่ กลับจุด ตาย เกิดใหม่ ทำงานบน tick ของเซิร์ฟเวอร์ |
| รางวัล | EXP, Job EXP, ของดรอป เพิ่มเฉพาะบนเซิร์ฟเวอร์ และบันทึกลงฐานข้อมูล |
| ข้อมูลผู้เล่น | Lv, Job, HP, แต้มสกิล, กระเป๋า อ่าน/เขียนเฉพาะเซิร์ฟเวอร์ |

## สิ่งที่ทำให้ย้ายได้ง่าย

โค้ดต่อสู้ในเกมตอนนี้แยก `CFG` (ข้อมูล) และ `Combat` (สูตร) ไว้แล้ว ขั้นแรกของ Phase 5 คือย้ายสองส่วนนี้ไปเป็นโมดูลที่ใช้ร่วมกันได้ทั้งเกมและเซิร์ฟเวอร์ ให้ค่าตรงกันทั้งสองฝั่ง
