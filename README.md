# Hmong Legend MMORPG V2.0

เกม MMORPG ธีมวัฒนธรรมและตำนานม้ง เล่นผ่านเว็บบนมือถือ Android และ iPhone

## โครงสร้าง

| ที่อยู่ | คืออะไร |
| --- | --- |
| `game/index.html` | ตัวเกม ไฟล์เดียว รูปฝังในไฟล์ (ฐาน: รอบ 4 มอนสเตอร์ตามแบบ V7) |
| `game/maps/` | ภาพแผนที่ (โหลดเมื่อเข้าโซน) — ต้องวางคู่กับ `index.html` |
| `game/sprites/` | ภาพมอนสเตอร์/บอส (โหลดเมื่อเข้าโซน) — ต้องวางคู่กับ `index.html` |
| `game/versions/` | สำเนาก่อนแก้แต่ละรอบ |
| `server/` | เซิร์ฟเวอร์ออนไลน์ (Node.js + WebSocket + SQLite) — `sim.js` ตัดสินการต่อสู้ |
| `shared/world.js` | กติกา/แมพ/CFG ที่ดึงจากไฟล์เกม ให้เซิร์ฟเวอร์ใช้ (สร้างอัตโนมัติ) |
| `tools/online-test.js` | ทดสอบออนไลน์ 2 เครื่อง |
| `tools/smoke-test.js` | สคริปต์ทดสอบอัตโนมัติ: โหลด เดิน จอย ต่อสู้ EXP เกิดใหม่ สกิล ย้ายโซน |
| `docs/STATUS.md` | สถานะงานทุกข้อ แยก ออกแบบแล้ว / พัฒนาแล้ว / รอทดสอบ / ทดสอบผ่าน / พบปัญหา |
| `docs/BUGS.md` | บันทึกบั๊ก |
| `docs/CHANGELOG.md` | ประวัติเวอร์ชัน |
| `docs/server-authority.md` | หน้าที่ของเซิร์ฟเวอร์ในระบบต่อสู้ (ออกแบบ) |
| `docs/ASSETS.md` | ที่มาและสัญญาอนุญาตของภาพจากภายนอก |
| `assets/` | ภาพต้นฉบับจากภายนอก (`third_party/`) และภาพที่สร้างแล้ว (`items/`) |
| `docs/evidence/` | ภาพและผลทดสอบที่อ้างในรายงาน |

## เล่นออนไลน์ (ทดสอบ 2 เครื่องในวง Wi‑Fi เดียวกัน)

ต้องมีคอมพิวเตอร์ที่ติดตั้ง Node.js 22.5 ขึ้นไป

```sh
cd server
npm install          # ครั้งแรกครั้งเดียว
npm start            # ขึ้น "Hmong Legend server: http://localhost:8080"
```

1. หา IP ของคอมพิวเตอร์ในวง Wi‑Fi (เช่น `192.168.1.20`)
2. มือถือเครื่องที่ 1 และ 2 ต่อ Wi‑Fi เดียวกัน เปิดเบราว์เซอร์ไปที่ `http://192.168.1.20:8080`
3. แต่ละเครื่องกด "สมัครใหม่" ด้วยชื่อคนละชื่อ (ชื่อ 3–16 ตัว รหัส 6 ตัวขึ้นไป)
4. เดินในหมู่บ้าน → อีกเครื่องจะเห็นตัวละครพร้อมชื่อบนหัว

ปุ่มทดสอบ "ตั้ง Job 30" ปิดอยู่บนเซิร์ฟเวอร์ปกติ ถ้าต้องการใช้ ให้รัน `ALLOW_DEBUG=1 npm start`

ถ้าเปิดไม่ได้ ให้ตรวจไฟร์วอลล์ของคอมพิวเตอร์ว่าเปิดพอร์ต 8080 แล้ว ฐานข้อมูลอยู่ที่ `server/data/hmong.db`

## ทดสอบ

ต้องมี Node.js และ Playwright (Chromium)

```sh
node tools/smoke-test.js            # ทดสอบ game/index.html บนหน้าจอจำลอง Pixel 7
```

```sh
(cd server && npm install)
node tools/online-test.js           # เซิร์ฟเวอร์จริง + 2 หน้าต่าง: สมัคร เห็นกัน มอนสเตอร์ร่วม ต่อสู้/รางวัลที่เซิร์ฟเวอร์ กันโกง ตาย/เกิด บันทึก
node tools/load-test.js 50 30 field2   # ทดสอบโหลด 50 คนในโซนเดียว 30 วินาที (ผลใน docs/LOAD_TEST.md)
node tools/sim-test.js              # ตรรกะเซิร์ฟเวอร์ล้วน ไม่ใช้เบราว์เซอร์
node tools/extract-shared.js        # รันทุกครั้งที่แก้แมพ/CFG/สูตรต่อสู้ใน game/index.html
```

ผลจะพิมพ์ PASS/FAIL ทีละข้อ และบันทึกภาพจอ `tools/last-run.png` กับผล `tools/last-run.json`
