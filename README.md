# Hmong Legend MMORPG V2.0

เกม MMORPG ธีมวัฒนธรรมและตำนานม้ง เล่นผ่านเว็บบนมือถือ Android และ iPhone

## โครงสร้าง

| ที่อยู่ | คืออะไร |
| --- | --- |
| `game/index.html` | ตัวเกม ไฟล์เดียว รูปฝังในไฟล์ (ฐาน: รอบ 4 มอนสเตอร์ตามแบบ V7) |
| `tools/smoke-test.js` | สคริปต์ทดสอบอัตโนมัติ: โหลด เดิน จอย ต่อสู้ EXP เกิดใหม่ สกิล ย้ายโซน |
| `docs/STATUS.md` | สถานะงานทุกข้อ แยก ออกแบบแล้ว / พัฒนาแล้ว / รอทดสอบ / ทดสอบผ่าน / พบปัญหา |
| `docs/BUGS.md` | บันทึกบั๊ก |
| `docs/CHANGELOG.md` | ประวัติเวอร์ชัน |
| `docs/server-authority.md` | หน้าที่ของเซิร์ฟเวอร์ในระบบต่อสู้ (ออกแบบ) |
| `docs/evidence/` | ภาพและผลทดสอบที่อ้างในรายงาน |

## เปิดเล่น

- มือถือ: เปิดลิงก์ artifact "Hmong Legend — รอบ 4 มอนสเตอร์ตามแบบ V7" บน claude.ai
- คอมพิวเตอร์: ดับเบิลคลิก `game/index.html` หรือเปิดผ่านเว็บเซิร์ฟเวอร์ใดก็ได้

ควบคุม: ลากนิ้วบนจอ (จอย) หรือปุ่มลูกศร/WASD เดิน · ปุ่ม ⚔ หรือ Space โจมตี · ปุ่มเลข 1–6 / คีย์ 1–9 ใช้สกิล · ปุ่ม "ชุด 2" สลับชุดสกิล · ⚙ เครื่องมือทดสอบ

## ทดสอบ

ต้องมี Node.js และ Playwright (Chromium)

```sh
node tools/smoke-test.js            # ทดสอบ game/index.html บนหน้าจอจำลอง Pixel 7
```

ผลจะพิมพ์ PASS/FAIL ทีละข้อ และบันทึกภาพจอ `tools/last-run.png` กับผล `tools/last-run.json`
